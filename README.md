# Python Data Pipeline & ETL

A modular ETL pipeline that extracts sales data, validates records, transforms business metrics, and produces analytics-ready output.

## Highlights
- Clean, modular implementation
- Runnable examples
- Practical error handling or validation where applicable
- Designed as a learning and portfolio project

## Workflow
Input -> Processing / Algorithm -> Output

## Quick Start
```bash
# Python projects
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```

For C++ projects, compile with a C++17-compatible compiler:

```bash
g++ -std=c++17 main.cpp -o app
./app
```

## Testing
Python projects include testable components where applicable:

```bash
pytest -q
```
